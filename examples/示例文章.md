## 代码块

```ts
import { marked } from 'marked';

const html = marked.parse('# Hello TypX');
console.log(html); // <h1>Hello TypX</h1>
```

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"

print(greet("TypX"))
```

## 数学公式

行内公式：质能方程 $E = mc^2$，欧拉恒等式 $e^{i\pi} + 1 = 0$。

块级公式：

$$
\int_{-\infty}^{\infty} e^{-x^2} \, dx = \sqrt{\pi}
$$

矩阵也支持：

$$
A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}, \quad \det A = ad - bc
$$
