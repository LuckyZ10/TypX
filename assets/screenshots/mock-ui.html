自定义主题样式

两个平台的管线独立，选项各自生效
CSS 会在复制时自动内联到每个元素上，直接粘贴到公众号 / 知乎即可生效。改完可先点「仅预览」看效果。

☁ 图床设置

公众号会过滤粘贴内容里的 base64 图片——本地图片和公式截图需要先上传图床换成 https 外链，粘贴时公众号自动转存。
知乎可直接 base64，无需图床。图片按内容哈希命名，同一张只传一次；Token 仅保存在本机。
