# TypX 使用教程

TypX 是一个本地优先的 Markdown 排版工具：打开你电脑上的文件夹写文章，套用主题排版，一键复制到微信公众号 / 知乎。所有文件都在本地，不经过任何服务器。

## 一、安装与启动

### 方式 A：从源码运行（开发者）

```bash
git clone <仓库地址>
cd TypX
npm install
npm run dev        # 构建并启动应用
```

> 国内网络若 Electron 下载失败，改用镜像：
> `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm install`

### 方式 B：免安装便携版

下载发布页的 `TypX-x.x.x-win-x64-portable.zip`，解压到任意目录，双击 `TypX.exe` 即可运行。不写注册表、不留安装残留，删除文件夹即卸载。

│       复制到公众号                                      │
├────────┬──────────────────┬──────────────────────────┤

- 编辑器滚动时预览同步滚动（可关闭）

## 三、项目系统

TypX 用「项目」管理你的文章文件夹，类似 IDE 的工作区：

- **自动登记**：任何一次「打开文件夹」都会把该目录登记为项目
- **自动恢复**：启动时自动打开最近使用的项目，并恢复该项目里**上次编辑到的那篇文章**
- **多项目切换**：点侧边栏顶部「📁 项目名 ▾」弹出项目面板：
  - 点击项目条目即切换（有未保存修改会先确认）
  - 悬停条目出现 ✕，可从列表移除（只删记录，不动磁盘文件）
  - 面板底部「＋ 打开新文件夹…」添加新项目
- 文件树自动递归扫描 `.md` / `.markdown` / `.mdx`，跳过 `node_modules`、`.git` 等目录；文件夹在外部有增删改时自动刷新，正在编辑的文件被外部修改且本地无改动时自动重载

## 四、写文章

- **打开文章**：左侧文件树点击任意 `.md` 文件
- **保存**：`Ctrl+S` 写回原文件；状态栏实时显示「● 未保存 / 已保存」和字数
- **外部修改**：文章被其他编辑器改动时（如 Obsidian、VS Code），TypX 自动重载；如果你本地有未保存修改，只提示不覆盖
- **编辑器字号**：「✎ 自定义样式」→ 编辑器字号（12–24px）

## 五、视图模式

顶栏三段式切换：

| 模式 | 用途 |
|---|---|
| ✏️ 编辑 | 纯写作，不分心 |
| ▤ 分屏 | 默认；左边写右边看 |
| 👁 预览 | 隐藏 Markdown 原文，整屏读排版；配合左侧文件树可以像看电子书一样连续切换文章 |

选择会被记住，下次启动保持上次的模式。

## 六、主题系统

### 内置主题（7 套）

| 主题 | 风格 | 适合 |
|---|---|---|
| 简约白 | 黑白极简，GitHub 风 | 通用 |
| 橙心 | 橙色标题 + 暖色块 | 通用、随笔 |
| 蓝绿清新 | 青绿色系 | 通用、技术 |
| 优雅紫 | 紫色标题条 + 淡紫块 | 生活、文艺 |
| 极客黑 | 深色底代码风 | 程序员读者 |
| **墨青标签** | 深黑灰 H2 标签块 + 珊瑚红加粗 + 墨青蓝斜体 | 技术长文（取自 Typlatex 装修） |
| **墨笺论文** | 衬线宋体 + 首行缩进 + 两端对齐 + 三线表 + 深色标签 H2，完整学术排版 | 论文风长文（Typlatex 完整移植） |

### 自定义主题

1. 顶栏「✎ 自定义样式」打开设置窗
2. CSS 编辑框里会预填当前主题的样式，直接修改（可先点「仅预览」看效果，不满意不保存）
3. 满意后点「保存并应用」——主题名可自定义，保存后出现在主题下拉的「我的主题」分组
4. 「删除此主题」可删除自定义主题（内置主题不可删）

CSS 按普通网页写法即可（选择器直接用 `h1`、`p`、`code` 等标签名），复制时 TypX 会把计算样式自动内联到每个元素上，粘贴到公众号 / 知乎不依赖外链样式。

### 其他排版设置（同一窗口）

- **文末脚注**：复制时自动附加在文末的居中灰字（如「本文使用 TypX 排版」），留空则不加
- **复制方案**：按平台分别配置（见[第九节](#九复制到公众号完整流程)）

## 七、数学公式

### 写法

```markdown
行内公式：质能方程 $E = mc^2$，欧拉公式 $e^{i\pi} + 1 = 0$。

块级公式（$$ 独占一行）：

$$
\int_{-\infty}^{\infty} e^{-x^2} \, dx = \sqrt{\pi}
$$
```

- 预览由 KaTeX 渲染，支持绝大多数 LaTeX 语法（上下标、分数、根号、矩阵、求和……）
- `$` 紧贴文字或标点也能识别（如 `($x$)`）；**正文中的美元符号写 `\$` 转义**，例如 `\$100`
- 单行块级写法 `$$ xxx $$` 也支持

### 复制时的公式处理（按平台独立配置）

| 模式 | 原理 | 适用 |
|---|---|---|
| 转行内 SVG（公众号默认） | MathJax 生成无 `defs` 的矢量 SVG，随字号缩放、无需图床、几百个公式也稳定 | **公众号（已实测验证）** |
| 转截图 PNG | 逐个截屏上传图床换外链 | 个别平台不支持 SVG 时 |
| 原样 HTML（知乎默认） | 公式 HTML 逐元素内联样式 | 知乎等对 HTML 宽容的平台 |

## 八、图片与图注

### 图片

```markdown
![说明](images/pic.png)          ← 相对路径（推荐，跟随项目）
![说明](./images/pic.png)        ← 同上
![说明](D:\docs\images\pic.png)  ← Windows 绝对路径
![说明](https://example.com/a.png) ← 网络外链
```

- 预览中本地相对路径图片通过本地协议直接显示，中文文件名、带空格都支持
- **复制时**：本地图片会被读取并以 base64 编码进剪贴板，公众号 / 知乎编辑器粘贴时一般会自动转存到平台图床；图片很多或平台转存失败时配置[图床](#十一图床配置详解)
- 网络外链图片原样保留，由平台转存

### 图注（墨青标签 / 墨笺论文主题）

图片单独成段，空一行后写**整段斜体**，自动变成蓝色居中的图注：

```markdown
![实验装置](images/setup.png)

*图 1：实验装置示意图*
```

## 九、复制到公众号（完整流程）

1. 写好文章，右侧确认排版效果
2. 点顶栏「**复制到公众号**」——提示会显示实际处理（如「382 个公式已转 SVG」）
3. 打开公众号后台图文编辑器，`Ctrl+V` 粘贴
4. 检查：标题样式、公式（矢量图）、图片（应已被转存为 mmbiz.qpic.cn 链接）

**公众号方案默认配置**（「✎ 自定义样式」→ 复制方案 → 公众号）：

- 公式：转行内 SVG（微信编辑器会剥掉公式 HTML 和 base64 图，但接受无 `defs` 的 SVG——这是 mdnice/doocs 验证过的方案）
- 图片：base64 直贴（图片不多时实测可用）；文章配图很多时建议开图床

**文末推荐（按平台独立配置）**：「✎ 自定义样式」→ 复制方案 → 文末推荐，填入 Markdown 格式的推荐链接。复制时会**自动加一条分割线**，渲染后追加到正文末尾（文末脚注之前）。典型用法：

```markdown
合集快速链接: [理解深度学习](https://mp.weixin.qq.com/mp/appmsgalbum?...album_id=xxx)  [CMOS工艺合集](https://mp.weixin.qq.com/mp/appmsgalbum?...album_id=yyy)

领域精读合集: [Thin Films Technologies Review](https://mp.weixin.qq.com/mp/appmsgalbum?...album_id=zzz)
```

公众号和知乎各配各的（比如知乎填知乎专栏/合集链接），留空则不追加。

**公众号的已知限制**：

- base64 图片可能被过滤（表现为贴过去图片空白）→ 开图床
- 公式 SVG 颜色跟随正文颜色（`currentColor`），极客黑深色主题下公式也是浅色，浅色主题同理
- 衬线字体（墨笺论文）在手机端回退为系统宋体，观感基本一致

## 十、复制到知乎

1. 点顶栏「**复制到知乎**」
2. 打开知乎编辑器（专栏/回答均可），`Ctrl+V` 粘贴

知乎方案默认：公式原样 HTML（知乎对富文本 HTML 更宽容）、图片 base64（知乎会自动转存）。这条管线是独立配置的初始方案，可根据自己的实测在「复制方案 → 知乎」里随时调整，不影响公众号方案。

## 十一、图床配置详解

**什么时候需要图床**：公众号粘贴后图片空白/丢失、或文章配图数量很多时。图片不多时通常不需要（base64 直贴即可，知乎更是完全不需要）。

### Gitee（国内快，推荐）

1. 注册/登录 [gitee.com](https://gitee.com)，新建一个**公开**仓库（例如 `images`，专门放图）
2. 头像 → 设置 → 安全设置 → **私人令牌** → 生成新令牌，勾选 `projects` 权限，复制令牌
3. TypX 顶栏「☁ 图床」→ 选 **Gitee**：
   - 令牌：粘贴私人令牌
   - 仓库：`你的用户名/images`
   - 分支：默认 `master`（按仓库实际填）
   - 目录：仓库内存放目录，如 `typx`
4. 点「测试图床（上传 1×1 测试图）」→ 显示 ✅ 和图片链接即成功 → 保存

> Gitee 上传接口有频率限制（约每小时 20 次），一次复制大量图片可能部分回退 base64。

### GitHub（无频率限制，国内网络可能不稳）

1. 新建公开仓库 + 生成 Personal Access Token（需 `repo` 权限）
2. 「☁ 图床」→ GitHub：填 Token、`用户名/仓库`、分支（常为 `main`）
3. 链接风格默认 jsDelivr CDN；粘贴后图片不显示时可切换 fastly 或 raw 试试

### SM.MS（最简单，免建仓库）

1. 注册 [sm.ms](https://sm.ms)（免费 5GB），访问 [sm.ms/apitoken](https://sm.ms/apitoken) 生成 API Token
2. 「☁ 图床」→ SM.MS → 只需填这一个 Token

### 图床工作原理

- 复制时，本地图片（和公式截图）自动上传图床，换成 `https` 外链——公众号粘贴时只转存外链图
- 图片按**内容哈希命名**：同一张图只占用一个路径；本地还有上传缓存（`upload-cache.json`），同一张图重复复制秒回、不再消耗请求次数
- 关闭图床时一切回到 base64 方案，随时切换

> 坚果云等 WebDAV 网盘**不能**用作图床：它们无法提供免登录的图片直链，公众号抓取不到内容。

## 十三、数据存储与备份

所有数据都在本地，无任何云端同步：

| 文件 | 内容 | 位置 |
|---|---|---|
| `preferences.json` | 项目列表、主题、图床配置、复制方案等全部偏好 | `%APPDATA%\TypX\` |
| `upload-cache.json` | 图床上传缓存（内容哈希 → 外链） | `%APPDATA%\TypX\` |

换电脑迁移：拷贝整个便携版文件夹 + 这两个 json 即可。图床 Token 以明文保存在本机 preferences.json，请勿把该文件分享给他人。

## 十四、常见问题 FAQ

**Q：公式复制到公众号乱码/散架？**
确认「复制方案 → 公众号 → 公式复制」选的是「转行内 SVG」。这是微信唯一稳定的公式方案（微信不支持公式 HTML，也不收 base64 图）。

**Q：公式预览正常，但复制提示「N 个公式按 HTML 原样复制」？**
说明该平台方案选了「原样 HTML」。公众号请改回 SVG。

**Q：图片粘贴到公众号不显示？**
图片不多时先确认是否开了「复制时处理本地图片」；仍不行则配置图床（Gitee 最省事）。知乎无此问题。

**Q：窄图片粘贴后不居中/偏移？**
已修复（复制时恢复 `margin:auto` 自适应居中）。如仍出现，请在 GitHub 提 issue 附截图。

**Q：墨笺论文主题的宋体在手机上还在吗？**
公众号会回退为手机系统衬线字体（iOS 宋体 / 安卓思源宋体），衬线观感基本保留，但与电脑预览不完全逐像素一致。

**Q：编辑（无预览）模式下点复制，公式截图模式会失效吗？**
不会，应用会临时切回分屏截屏再还原。SVG 模式则完全不受视图模式影响。

**Q：能把生成的排版导出成 HTML 文件吗？**
当前版本聚焦复制粘贴工作流；可用「复制 Markdown」+ 任何静态渲染器补充。

**Q：支持哪些 Markdown 语法？**
GFM 全套：表格、任务列表、删除线、引用块、代码块（highlight.js 高亮）等。
