# TypX

面向微信公众号与知乎的本地 Markdown 写作、排版和发布工具。

[下载最新 Windows 安装包](https://github.com/LuckyZ10/TypX/releases/latest)

## 下载与安装

请在最新 Release 中下载 `TypX-Setup-x.x.x.exe`。安装向导允许选择安装目录，并可创建桌面与开始菜单快捷方式。

从 v0.6.2 起，安装版支持在 TypX「设置」中自动检查、下载并安装后续版本。

## v0.7.0 重点更新

- 重整桌面界面与项目、编辑、预览、发布流程
- 支持坚果云 WebDAV 项目同步
- 新增复制文件完整路径、公众号发布标记和 Markdown 语法提醒
- 点击预览内容可定位并高亮对应 Markdown 源码
- 修复公众号中文公式、`\\text{}`、列表换行和公式空白问题
- 长块公式支持在公众号中横向滑动，不再裁掉右侧内容

## Release 文件说明

- `TypX-Setup-x.x.x.exe`：Windows 安装包
- `latest.yml`、`.blockmap`：TypX 自动更新所需文件
- `SHA256SUMS.txt`：下载完整性校验
